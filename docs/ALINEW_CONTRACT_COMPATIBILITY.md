## 1. Executive Summary

This document establishes structural, field-level compatibility between the production enterprise contracts of **Ralion OS** (`rasali535/alinew`) and the standalone **Meta AI Edition** (`ralion-meta-hackathon`). 

The hackathon application is intentionally clean-room and independently deployable with **zero runtime dependencies on production Ralion OS**. However, to ensure post-hackathon reintegration is mechanical and seamless, the data models, interfaces, and lifecycle states in Meta AI Edition must mirror production shapes.

## 3. Contract Compatibility Matrix

### 3.1 Creative Asset Core: `CreativeProviderRequest` & `CreativeProviderResult`

#### Production Contract (`alinew:packages/ai/src/creativeProvider.interface.ts`)
```typescript
export type CreativeAssetType = 'POSTER_IMAGE' | 'VIDEO_REEL';

export type CreativeLifecycleState =
  | 'QUEUED'
  | 'GENERATING'
  | 'VALIDATING'
  | 'STORING'
  | 'COMPLETED'
  | 'FAILED';

export interface CreativeProviderRequest {
  type: CreativeAssetType;
  prompt: string;
  style?: string;
  format?: string;
  width?: number;
  height?: number;
  seed?: number;
  timeoutMs?: number;
}

export interface CreativeProviderResult {
  buffer: Buffer;
  mimeType: string;
  providerName: string;
  durationSeconds?: number;
  generationTimeMs: number;
}
```

#### Meta AI Edition Implementation (`apps/meta-os/lib/creative.js` & `lib/creative-store.js`)
- **Observed Alignment:**
  - `apps/meta-os/lib/creative.js` generates binary imagery via Meta Responses or mock generator and produces binary buffers with verified `mimeType` (`image/png`, `image/jpeg`, `image/webp`, `image/gif`).
  - Assets are stored with metadata: `assetId`, `prompt`, `bytes`, `sha256`, `mimeType`, `reviewStatus`, `createdAt`.
- **Status:** **COMPATIBLE**
- **Remaining Gap:** Meta AI Edition currently lacks a formal `CreativeProvider` class interface implementation for `muse-image-1.0`. It calls `generateWithMuseImage` via a procedural function in `lib/meta/provider.js`.
- **Recommendation for Muse:** Introduce a clean-room adapter class `MetaImageProvider implements CreativeProvider` in `apps/meta-os/lib/creative-provider.js` that implements `generate(req: CreativeProviderRequest): Promise<CreativeProviderResult>`.

### 3.2 Social Handoff Contract: `SocialHandoffContract`

#### Production Contract (`alinew:packages/ai/src/creativeProvider.interface.ts`)
```typescript
export interface SocialHandoffContract {
  assetId: string;
  organizationId: string;
  workspaceId: string;
  mediaUrl: string;
  mediaType: 'image' | 'video';
  title: string;
  caption: string;
  campaign: string;
  platform: string;
  cta: string;
}
```

#### Meta AI Edition Implementation (`apps/meta-os/lib/social-copy.js` & `views/social.jsx`)
- **Observed Alignment:**
  - `buildSocialDrafts(mission)` constructs channel-specific copies for Facebook and Instagram:
    - Facebook: storytelling caption, call to action (`cta`), fact grounding.
    - Instagram: visual caption, curated hashtags (bounded to 5), fact grounding.
  - In `views/social.jsx`, the creative asset thumbnail is directly bound to the social draft cards.
- **Status:** **PARTIALLY COMPATIBLE**
- **Remaining Gap:** The draft objects generated by `social-copy.js` currently use `{ channel, copy, caption, cta, hashtags, grounding }`. They do not explicitly bundle `organizationId`, `workspaceId`, `assetId`, and `mediaUrl` into a unified `socialContract` sub-object.
- **Recommendation for Muse:** When a mission plan is minted or updated with generated creative assets, attach a formal `socialContract: SocialHandoffContract` record to each channel entry in `mission.social`.

## 4. Design System & Brief Compatibility

### 4.1 Brief Model (`creativeBrief.types.ts` vs `apps/meta-os/lib/image-prompt.js`)

In production, `StructuredCreativeBrief` separates copy hierarchy (`headline`, `bodyCopy`, `cta`, `contactDetails`) from the visual generation direction (`visualDirection.prompt`, `negativeSpacePlacement`).

In Meta AI Edition:
- `buildImagePrompt` in `apps/meta-os/lib/image-prompt.js` maps `businessName`, `businessIndustry`, and `brief` text into a clean visual prompt.
- `SOCIAL_DIMENSIONS` (1:1 Square 1080x1080, 4:5 Portrait 1080x1350, 16:9 Landscape 1200x675, 9:16 Story 1080x1920) is defined in `src/contracts/creativeBrief.types.ts`.

Muse should import `SOCIAL_DIMENSIONS` from `src/contracts/creativeBrief.types.ts` into `CreativeView` to provide aspect-ratio selection buttons (1:1, 9:16) for Meta Muse Image.

## 5. Strategic Growth Compatibility

### 5.1 Growth Memory (`businessGrowthProfile.service.ts` vs `apps/meta-os/app/views/growth.jsx`)

In production, `BusinessGrowthProfile` structures growth opportunities into:
- `id`, `title`, `category` (`REVENUE_EXPANSION` | `MARKETING_ACQUISITION` | `CUSTOMER_RETENTION` | `OPERATIONAL_VELOCITY`)
- `whyMariRecommends`, `evidence`, `impact`, `urgency`, `confidence`, `expectedOutcome`

In Meta AI Edition:
- `planMission` in `apps/meta-os/lib/mission.js` extracts:
  - `opportunity`: Strategic focus statement
  - `reason`: Grounded explanation based on intake/website facts
  - `measurement`: Metric target
- Compatibility is high. Muse can augment `mission.growth` with `category: 'MARKETING_ACQUISITION'` and `confidence: 0.88` to align with the production scorecard.
